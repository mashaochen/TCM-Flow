# 案例二：柚皮素 + Crambin (1CRN) 七阶段全流程计算

## 说明

本案例选择柚皮素（Naringenin）与 Crambin（PDB ID: 1CRN）进行完整的
七阶段全流程计算，用于演示 TCM-Flow 平台的全自动化管线能力。

选择 Crambin 的原因：
- 小蛋白（46 个氨基酸，约 640 个原子），计算速度快
- 结构洁净，无缺失残基，适合方法学验证
- 常用于分子动力学方法测试

## 运行方法

```bash
# 方法一：通过平台 Web 界面
# 1. 启动平台后访问 http://localhost:5589
# 2. 搜索"枳实"或"化橘红"，选择"柚皮素"
# 3. 输入 PDB ID: 1CRN
# 4. 提交任务，等待七阶段计算完成
# 5. 查看 AI 智能报告

# 方法二：通过 API 提交
python run_case2_api.py
```

## 七阶段说明

| 阶段 | 名称 | 方法 | 输出 |
|------|------|------|------|
| 1 | 分子对接 | AutoDock Vina 1.2.7 | 对接构象 + 亲和力 |
| 2 | 几何优化 | GFN2-xTB | 优化后构象 + 能量 |
| 3 | 再对接 | AutoDock Vina | 优化后对接亲和力 |
| 4 | 分子动力学 | OpenMM | 轨迹文件 + 能量日志 |
| 5 | 性质提取 | GFN2-xTB | 能隙、偶极矩、电荷 |
| 6 | 轨迹分析 | MDTraj / NumPy | RMSD、Rg、RMSF |
| 7 | AI 报告 | Ollama + LLM | 结构化分析报告 |

## 预期结果

- 对接亲和力：约 -5 ~ -6 kcal/mol
- MD 模拟：体系稳定，RMSD < 0.1 nm
- AI 报告：包含分子性质、对接解读、动力学分析

> 注意：默认使用测试档配置（生产 MD 1000 步 / 0.5 ps），
> 正式研究请在 config.py 中设置 TEST_MODE = False
> 以使用生产档配置（500,000 步 / 250 ps）。
