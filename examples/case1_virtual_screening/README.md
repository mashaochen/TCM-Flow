# 案例一：7种中药黄酮类成分对 FAK (PDB: 2J0L) 虚拟筛选

## 说明
本案例从黄芩、枳实等常用中药中选取 7 种代表性黄酮类活性成分，
对 FAK（focal adhesion kinase，PDB ID: 2J0L）进行分子对接虚拟筛选，
用于演示 TCM-Flow 平台的批量虚拟筛选能力。

## 配体列表（与论文 Table 1 一致）

| 编号 | 中文名 | 英文名 | 来源中药 |
|------|--------|--------|---------|
| 1 | 柚皮素 | Naringenin | 枳实、化橘红、骨碎补 |
| 2 | 山柰酚 | Kaempferol | 银杏叶、山楂、红花 |
| 3 | 槲皮素 | Quercetin | 槐米、银杏叶、三七 |
| 4 | 黄芩素 | Baicalein | 黄芩 |
| 5 | 芹菜素 | Apigenin | 芹菜、白花蛇舌草 |
| 6 | 木犀草素 | Luteolin | 金银花、菊花、荆芥 |
| 7 | 染料木素 | Genistein | 槐角、大豆、葛根 |
