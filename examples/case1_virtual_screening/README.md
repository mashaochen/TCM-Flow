# 案例一：7种中药黄酮类成分对 FAK (PDB: 2J0L) 虚拟筛选

## 说明

本案例从黄芩、枳实等常用中药中选取 7 种代表性黄酮类活性成分，
对 FAK（ focal adhesion kinase，PDB ID: 2J0L）进行分子对接虚拟筛选，
用于演示 TCM-Flow 平台的批量虚拟筛选能力。

## 配体列表

| 编号 | 中文名 | 英文名 | 来源中药 |
|------|--------|--------|---------|
| 1 | 柚皮素 | Naringenin | 枳实、化橘红 |
| 2 | 山柰酚 | Kaempferol | 银杏、槐花 |
| 3 | 槲皮素 | Quercetin | 槐米、银杏叶 |
| 4 | 黄芩素 | Baicalein | 黄芩 |
| 5 | 芹菜素 | Apigenin | 芹菜、洋甘菊 |
| 6 | 木犀草素 | Luteolin | 金银花、菊花 |
| 7 | 葛根素 | Puerarin | 葛根 |

## 运行方法

```bash
# 方法一：通过平台 Web 界面
# 1. 启动平台后访问 http://localhost:5589
# 2. 搜索"黄芩"，选择"黄芩素"
# 3. 输入 PDB ID: 2J0L
# 4. 提交任务，等待计算完成

# 方法二：Python 脚本批量运行
python run_case1.py
```

## 预期结果

7 种黄酮均能成功对接，亲和力范围约 -5 ~ -9 kcal/mol。
排序因 Vina 随机种子和对接盒子设置可能略有差异。
