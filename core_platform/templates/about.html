🧪 关于本平台

TCM-Flow 是一个面向中医药活性成分靶点发现与机制研究的全流程分子计算平台。 用户输入小分子配体的 SMILES 与靶蛋白的 PDB 结构，平台自动完成完整的计算流水线： 分子对接 → xtb 半经验优化 → 优化后再对接 → 分子动力学模拟 → 性质提取 → 轨迹分析 → 汇总报告。

平台最终输出一份文字总结报告（对接亲和力、HOMO-LUMO 能隙、偶极矩、RMSD/Rg/RMSF 等关键指标）， 供快速筛查与机制研究参考。所有原始输出文件（复合物 PDB、轨迹、日志等）均归档在本机， 用户界面仅提供文字报告，如需原始数据请联系管理员。

技术栈（均为开源）

AutoDock Vina {{ vina_version }}（Apache 2.0） xtb（GFN2-xTB） OpenMM MDTraj RDKit Flask

数据来源：蛋白结构可经 PDB ID 从 RCSB Protein Data Bank（https://www.rcsb.org）下载，或上传本地 PDB 文件。
